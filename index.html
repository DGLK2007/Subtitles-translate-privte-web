How to Use

  1. Go to Settings → add your OpenRouter API key → choose model + speed preset.
  2. Select target language (default: Natural Spoken Sinhala), styling & watermark.
  3. Upload .srt / .ass / .zip files — multiple at once.
  4. Click Translate Files — progress bar shows lines, dedup savings & time remaining.
  5. Click Download Translated ZIP to get all files in one ZIP.

Speed Tips

  1. Gemini 2.0 Flash is the fastest + cheapest for Sinhala — recommended.
  2. Higher parallel workers = faster, but may hit rate limits on free tier.
  3. Larger batch size = fewer requests, but can fail on very long lines.
  4. For 1000+ lines, use Ultra Fast preset — 5–10x faster than default.
