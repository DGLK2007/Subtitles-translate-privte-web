How to Use

  1. First go to Settings and add your OpenRouter API key + choose a model.
  2. Select target language (default: Natural Spoken Sinhala), styling & watermark.
  3. Upload .srt / .ass / .zip files — multiple at once.
  4. Click Translate Files and wait for progress to reach 100%.
  5. Click Download Translated ZIP to save all files.

API Settings

Stored only in your browser's localStorage. Never uploaded anywhere. Get a key at openrouter.ai/keys.
Larger batches = fewer API calls = faster, but can hit token limits on long subtitle lines.

Recommended Models

  1. Gemini 2.0 Flash — Best price/quality for Sinhala translation, very fast.
  2. Llama 3.3 70B — Good quality, sometimes free on OpenRouter.
  3. GPT-4o Mini — Reliable, good Sinhala output.
  4. Claude 3.5 Haiku — Excellent natural language quality.
